# academic_learning_skills

Reusable academic paper-reading skills for evidence-first, figure-centered biomedical and AI literature study.

## Included

- `skills/academic-paper-reading/SKILL.md` — primary reading workflow.
- `skills/academic-paper-reading/references/figure-analysis.md` — detailed figure and screenshot interpretation checklist.
- `dist/academic-paper-reading.skill` — distributable skill archive.

The skill is designed for structured reading notes, primary-source verification, deep figure teaching, evidence boundaries, medical-AI terminology, and reproducible Markdown/HTML project workflows.
